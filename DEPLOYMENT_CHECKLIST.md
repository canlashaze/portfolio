## 🆘 TROUBLESHOOTING

### "My portfolio isn't showing"
1. Did you enable GitHub Pages? → Check Settings → Pages
2. Wait 2-3 minutes for initial deployment
3. Hard refresh browser (Ctrl+Shift+R or Cmd+Shift+R)

### "Photo isn't showing"
1. Check file is named `profile.jpg`
2. Verify it's in `assets/` folder
3. Hard refresh to clear cache
4. Check browser console for errors

### "Links aren't working"
1. Verify email format: `mailto:your@email.com`
2. Verify phone format: `tel:+1234567890`
3. Verify LinkedIn URL is correct
4. Test in incognito mode

### "Site looks different on mobile"
1. Check viewport meta tag (already included)
2. Test in device dev tools (F12)
3. All responsive breakpoints covered
